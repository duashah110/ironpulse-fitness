# IronPulse Fitness - Website

**Live site:** https://ironpulse-fitness-rho.vercel.app/
**Tech:** HTML, CSS, JavaScript (no frameworks)

## Features
- Sticky navbar with mobile menu
- Animated hero, scrolling ticker, animated counters
- Services, trainers, membership plans, FAQ
- Photo gallery with lightbox
- BMI calculator
- Contact form (Formspree-ready) and WhatsApp button

## Run locally
Open `index.html` in a browser.
